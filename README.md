# BIJJU MULTY SERVICES – Android App Starter

A React Native + Expo starter for the BIJJU MULTY SERVICES mobile app.

## Included
- Premium navy and gold interface
- 16 services based on the current public website
- Guest service enquiry form
- Local demo booking list
- WhatsApp enquiry to 9617643254
- Contact details and service disclaimer

## Run locally
1. Install Node.js (LTS) on a computer.
2. Install dependencies: `npm install`
3. Start: `npx expo start`
4. Scan the QR code with Expo Go on Android.

## Important – demo limitations
This is a frontend starter, not a production backend. Enquiries/bookings are stored only in app memory and are lost when the app restarts. OTP login, persistent customer accounts, admin dashboard, live booking notifications, payment gateway and cloud database are **not connected yet**. Do not collect or upload Aadhaar, PAN, banking credentials, OTPs or other sensitive documents until a secure backend and privacy process are implemented.
